# VS Code Dark Modern syntax theme

From [microsoft/vscode](https://github.com/microsoft/vscode/tree/f9ff1d3d91db7145b0723a3da2a4c0179bad4ad6/extensions/theme-defaults/themes), commit `f9ff1d3d91db7145b0723a3da2a4c0179bad4ad6`, under the included MIT license.
