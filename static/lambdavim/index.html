LambdaVim

Neovim config without the bloat - everything is in your control.

LambdaVim is a minimal, modern Neovim configuration designed for developers who want a clean and productive editing experience without the bloat. While it is meant to work straight out of the box, you can easily customize it to your liking by adding more plugins.

Installation

Back up your current config if you have one: 
mv ~/.config/nvim ~/.config/nvim.bak
Clone LambdaVim: 
git clone https://github.com/smit4k/LambdaVim ~/.config/nvim
Launch Neovim: 
nvim

Features

  • File tree
  • LSP
  • Syntax highlighting
  • Formatter
  • Statusline
  • Git signs
  • Telescope
  • Dashboard

LambdaVim is a starting point for your own Neovim config. Change the keybindings, swap plugins, add more colorschemes. Everything lives in your config.
